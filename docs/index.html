cgmlst-dists-rs

Pairwise cgMLST distance matrix from chewBBACA allele calls. A Rust port of Torsten Seemann's cgmlst-dists that gives the same matrix, md5 for md5, 16 to 20 times faster on the same machine.

Independent port, not affiliated with or endorsed by the original author. cgmlst-dists is GPL-3.0, and so is this port.

Three Listeria monocytogenes genomes, Pasteur cgMLST scheme (1 748 loci). Allele ids are CRC32 hashes, up to 4 294 967 295. *557 and *486 are novel alleles; 0 is a missing call. A distance counts the loci where both genomes have a call and the calls differ.

Install

Bioconda
conda install -c bioconda cgmlst-dists-rs
The conda binary is named cgmlst-dists-rs, so it can share an environment with the original cgmlst-dists.
Docker
docker pull ghcr.io/genpat-it/cgmlst-dists-rs
Debian slim, portable AVX2 build.
Cargo
RUSTFLAGS="-C target-cpu=native" cargo install cgmlst-dists-rs
target-cpu=native enables AVX-512 where the CPU has it.
GPU
docker run --gpus all ghcr.io/genpat-it/cgmlst-dists-rs:cuda --gpu -i …
NVIDIA GPUs from the T4 to the H100; the image needs only the driver. Or cargo install cgmlst-dists-rs --features cuda with the CUDA toolkit. The other builds are CPU-only.

Run

cgmlst-dists -i chewbbaca.tsv -o distances.tsv
cgmlst-dists -i chewbbaca.tsv -m lower-tri > distances.tsv
cgmlst-dists -i chewbbaca.tsv -o distances.tsv.gz   # parallel gzip
cgmlst-dists -i chewbbaca.tsv -N -o distances.tsv   # count *N novel alleles

All options are in the README.

Reading the table

cellread as
3145974256an allele id. Any non-negative integer up to 264−1, so CRC32 hashes work
INF-42allele 42. chewBBACA's INF- prefix for inferred alleles is stripped
*486a novel allele, not yet in the schema. Missing by default; compared as an allele with -N
LNF, PLOT3, PLOT5, ASM, ALM, NIPH, NIPHEM, LOTSCchewBBACA classes for loci without a clean call: missing
0, -, emptymissing (-n sets the missing character)

Use -N only on a table from a single chewBBACA run: the *N numbers are local to the run that assigned them.

Releases up to 0.1.2 parsed alleles as 32-bit signed integers and treated every hash above 231 as missing, about half of a hashed profile. On the genomes above they reported 282 and 11 instead of 1 196 and 35. Fixed in 0.1.3.

Synthetic: 50 000 genomes × 5 000 loci, distance computation

cgmlst-dists-rs, 80 CPU threads71 s
cgmlst-dists-rs --gpu, NVIDIA L45.6 s

Full matrix, best of three, on an 80-core x86-64 machine with AVX-512. The C tool was built with its Makefile (-Ofast -fopenmp) and run with -j set to the core count and -x 100000, so both compute the same matrix; their outputs have the same md5. Each group is drawn to its own scale. The GPU and CPU paths also give the same md5; with reading and writing the 50 000 × 50 000 matrix, the totals are 76 s and 11 s. Below about 10 000 genomes the CPU is faster.

# reproduce: no datasets are shipped, generate them
python3 scripts/generate_profiles.py -n 20000 -l 3000 -o bench.tsv
time cgmlst-dists -i bench.tsv -o out.tsv

The distance loop is written so LLVM vectorizes it: 16 loci per AVX-512 instruction. Only the upper triangle is computed, and parsing, distances and output formatting all run on every core.
